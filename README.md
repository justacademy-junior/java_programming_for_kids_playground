# Java Programming for Kids: Understanding Variables, Loops and Conditions Through Examples

A playful, interactive landing page that explains the three big ideas behind every Java program, using things kids already know: jars, traffic signals and playground laps.

Everything runs in the browser with plain HTML, CSS and JavaScript. There is no build step and no dependency to install, so it works perfectly on GitHub Pages.

## What is inside the page

* **The score jar** in the hero. Add or spend points and watch a Java variable change.
* **Variables as jars.** Four live cards for int, double, String and boolean. Edit a value and the Java line updates.
* **Conditions as traffic signals.** Choose red, yellow or green, or let it auto cycle, and see which branch of the if, else if and else code lights up.
* **Loops as playground laps.** Switch between a for loop and a while loop, pick the number of laps and run it.
* **The canteen mix.** One small program that uses a variable, a loop and a condition together.
* **Six clickable link cards**, a sticky header and a full footer.

## Run it locally

1. Download or clone this repository.
2. Open `index.html` in any modern browser.

## Publish with GitHub Pages

1. Create a new repository and upload `index.html` and `README.md` to the root.
2. Open **Settings**, then **Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and the `/ (root)` folder, then press **Save**.
5. After a minute, your page is live at `https://YOUR_USERNAME.github.io/REPOSITORY_NAME/`.

## Customise

* **Colours** live in the `:root` block at the top of the style section.
* **Fonts** are Lilita One and Nunito, loaded from Google Fonts.
* **Links** are normal anchor tags, so you can change any URL by editing its `href`.
* **Canteen kids and money** are in the `kids` array inside the script.

## Good to know

* Responsive from small phones to wide desktops.
* Keyboard focus is clearly visible and screen readers get live updates for the interactive outputs.
* Motion is switched off automatically for visitors who prefer reduced motion.
