Java for kids starts with jars, signals and laps.

Every Java program is built from three ideas: variables that remember, conditions that decide and loops that repeat. Play with each one on this page, no typing skills needed.

Variables are labelled jars

      
A variable has a name on the outside and a value on the inside. Java also needs to know what kind of thing the jar holds. Change each jar below and see the Java line update.

    

    

      

        int
        
10

        
Whole numbers, like age or number of books.

        
        

      

      

        double
        
4.5

        
Numbers with a decimal point, like height or price.

        
        

      

      

        String
        
Aarav

        
Words and names, always inside double quotes.

        
        

      

      

        boolean
        
true

        
Only true or false, like a light switch.
